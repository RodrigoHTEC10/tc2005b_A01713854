Una Rich Internet Application es una aplicación web que ofrece caracteristicas y una experiencia de usuario similar a la de las aplicaciones de escritorio tradicionales completamente ejecutadas desde un navegador.

Entre sus características principales se encuentran:

  • Responden en tiempo real a las acciones del usuario
  • Actualiza el contenido de forma dinámica y parcial.
  • Posee una interfaz pulcra y limpia.

AJAX permite dentro de estas aplicaciones comunicación asincrona con el servidor, permitiendo el envio y la recepcion de datos sin perder control de ejecusión ni requerir una recarga completa de la página; actualización parcial del DOM; una mejor experiencia de usuario y separación entre la presentación y la lógica detras del msimo.

El uso de AJAX genera vulnerabilidades debido a la apertura de diversos canales de comunicación entre el servidor y el cliente, algunos de estos son:

  • Cross-Site-Scripting: Datos maliciosos son injectados directos en el navegador y ejecutados como codigo de JS.
  • Cross-Site Request Forgery: Cuando un sitio malicioso engaña al navegador para realizar peticiones no autorizadas a un sitio con sesión iniciada.
  • SQL Injection: Manipulacion de la base de datos a traves de parametros sin sanitizar enviados a base de datos.
  • Exposición de APIs
  • Man-in-the-Middle: Un intermediario puede interceptar y modificar datos en tránsito.

Las validaciones de seguridad deben ser siempre realzadas en el servidor y tambien en el cliente. Esto se debe manejar asi, ya que aunque se regulen las restricciones en frontend, es posible desabilitar el JS dentro del mismo, lo que permite sobrepasar la primer linea de seguridad. Al tener verificaciones, tanto en el servidor como en el cliente, añadimos una capa de seguridad adicional para usuarios comunes.

JSON (JavaScript Object Notation) es un formato ligero de intercambio de datos estructurado jerarquico que es fácil de leer tanto para el humano como la computadora.

Su estructura se compone de clave: valor entre llaves { }

{ "nombre": "Ana", "edad": 25, "activo": true }

A traves de este es posible enviar:

  • String
  • Int
  • Float
  • Boolean
  • null
  • Object
  • Array

Ventajas:

  • Ahorro de tiempo y recursos al emplear funcionalidades ya probadas
  • Reducción de costos (Especialistas o arquitectura necesaria)
  • Calidad y confiabilidad
  • Actualizaciones automáticas
  • Escalabilidad
  • Seguridad especializada

Desventajas:

  • Dependencia de un servicio que no se controla
  • Riesgos de seguridad y privacidad
  • Costos variables e impredescibles debido a la influencia del uso y consumo del cliente
  • Falta de control
  • Latencia adicional
  • Limites y restricciones en el servicio
  • Siempre existe la posibilidad que se descontinue el servicio
